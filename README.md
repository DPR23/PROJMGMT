## ✨ Features

Experience a new level of productivity with our carefully crafted feature set:

- **📋 Kanban Board** – Intuitive drag-and-drop task management
- **📊 Interactive Dashboard** – Real-time analytics and insights at a glance
- **📅 Gantt Chart** – Beautiful visualization for project timelines
- **⏱️ Time Tracking** – Built-in live timer for accurate billing and tracking
- **🔄 Real-time Collaboration** – Seamless syncing via Socket.io
- **🎨 Beautiful Apple-inspired UI** – Clean, modern, and fluid animations
- **📱 Fully Responsive** – Works flawlessly on desktop, tablet, and mobile
- **🚀 One-click Deployment** – Vercel-ready out of the box

## 🚀 Quick Start

Get ProjectFlow up and running on your local machine in minutes.

```bash
# Clone the repository
git clone https://github.com/DPR23/PROJMGMT.git
cd PROJMGMT

# Install frontend dependencies
cd frontend 
npm install 
cd ..

# Install backend dependencies
cd backend 
npm install 
cd ..

# Start development servers
# Terminal 1
cd backend 
npm run dev  

# Terminal 2
cd frontend 
npm run dev
```
